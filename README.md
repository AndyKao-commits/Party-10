# PBON｜派對系統

一打開就是仿 ibon 的售票站。後台可建立／編輯活動、假活動、假信用卡。

主打搶票場預設為 **YAWASABI「SUPER PLANET」in TAIPEI**。

## 你現在要做（Supabase）

在 SQL Editor **依序執行**（若尚未跑過）：
1. `supabase/schema.sql`
2. `supabase/schema-v2.sql`（假活動、假卡）
3. `supabase/schema-v3.sql`（活動海報欄位 + 寫入 YAWASABI 主打場）
4. `supabase/schema-v4.sql`（座位、真假隨機排列、完整編輯與刪除、新烤肉海報活動）
5. `supabase/schema-v5.sql`（取消訂單、清除購票紀錄並釋回真座位）
6. `supabase/schema-v6.sql`（網站開關、預先註冊登入、會員限定購票與會員重置）

已使用 v3 的資料庫只需執行 v4，請勿重跑 v3（會覆寫主打活動庫存）。先更新資料庫，再使用本版網站。

後台可編輯各票區名稱、票價、顏色、真／假座位數，以及活動文案、時間、海報、主打設定。調整座位數保留已售座位，改票價不重置庫存，原訂單保留成交票價。已售票區不可單獨移除；刪除整個活動會連同座位、玩家及訂單永久刪除。新烤肉活動預設 18 真／18 假、NT$700，主辦可自由修改。

購票紀錄可逐筆取消，或按目前篩選一次清除單一活動／所有活動；相關真座位與票區庫存會同步恢復。

假卡後台會產生仿真但不可付款的卡片資料，顯示正反兩面；可逐張匯出 PNG，或依標準卡片尺寸排列成 A4 正反面列印頁，每頁 8 張並批量匯出 ZIP。

網站、註冊與購票可在後台分別開關。網站暫停時仍可預先註冊或登入；會員以帳號＋電話登入，電話同時作為密碼。預設工作人員瀏覽密碼為 `preview2026`，請登入後台後立即改成自己的密碼。

購票依序選票區、點選座位、填寫假卡資料。只要包含假座位，整筆交易顯示「你是黃牛不賣你 請重新購票」，不建立訂單、不扣庫存。真假位置只存在未公開的資料表，前端只收到座位編號與已售狀態。選位不保留；購票完成時以資料庫鎖保證不重複出售。

驗證：`npm test`（座位邏輯與本機 HTTP 流程）、`npm run test:sql`（隔離 PostgreSQL 引擎測試遷移、假座位回滾、重複購買、改價與刪除）、`npm run build`。SQL 測試不連接線上資料庫。

Vercel 環境變數不用動；部署後重新 Deploy。

## 後台 `/admin`（手機友善）

密碼預設 `party2026`

分三頁：
1. **活動**：建立／編輯、總限量、海報上傳或貼網址、開賣時間、立刻開賣
2. **假活動**：改標題、文案、上傳／貼圖片（不會真的賣票）
3. **假信用卡**：一次產生多張（卡號／月年／四碼 CVV），分享給現場；結帳要輸入正確才過

## 訪客結帳

必須使用主辦發給的假卡資料刷卡（假的，不會真扣款）。
